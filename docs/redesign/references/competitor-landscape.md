## Table-stakes patterns (2025–2026)

1. **Highlight-in-text + anchored card column**, with floating popover fallback; density toggle expected.
2. **A filterable all-comments panel** with jump-to-anchor and open/resolved/person filters.
3. **Resolve hides but never destroys** — resolved threads stay one click away with reopen.
4. **Anchor resilience with explicit orphan UX** — Hypothesis's quote+prefix/suffix fuzzy re-anchoring is the reference; CriticMarkup carries the quoted text inline, a natural fit.
5. **Keyboard-first review triage** — Google Docs (J/K/E/R/U), Reviewable (`n`/`j`), Figma (C).

## Differentiation opportunities

1. **Typed human comments for LLM consumption — completely unoccupied.** Every human-side tool has one flat comment type.
2. **CriticMarkup write-back as the interchange format** — survives any editor, git diff, and agent context window.
3. **Local-first + encrypted peer links** — nobody combines files-on-disk with no-account guest review.
4. **Review batching for agent handoff** — GitHub's pending-review model doesn't exist in this category.
5. **Keyboard-driven doc review** at Reviewable/Google grade.

## Visual/typography benchmarks worth emulating

- **Typora** — seamless WYSIWYG, Focus/Typewriter modes: the rendering-quality bar.
- **iA Writer** — sentence focus, Duo/Quattro faces; Authorship coloring for AI-pasted text.
- **Marked 2's CriticMarkup tri-view** — Markup / Original / Edited: a preview of "accept everything."
- **Bear** — comfort bar for non-technical reviewers.
- **HackMD overlap shading**, **Word's Simple Markup change-bar**, **Grammarly per-type underline colors**.

**Strategic finding:** the "review AI-generated markdown" category is real but embryonic. No player has typed comments, CriticMarkup output, review batching, or a peer-sharing story together.
